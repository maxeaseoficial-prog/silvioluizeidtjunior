# PSV Structure Blueprint

OBJETIVO

Crie SOMENTE O ESQUELETO VISUAL de uma página de vendas profissional, single-page, para:

MÉTODO PSV

Processo, Sistema e Vendas.

Especialista:

Silvio Luiz Eidt Junior

Produto/serviço:

Estruturação de Equipe de Vendas.

IMPORTANTE SOBRE ESTA ETAPA

Esta etapa será feita na Lovable somente para estabelecer:

- estrutura da página;

- direção visual;

- hierarquia;

- seções;

- componentes básicos;

- responsividade inicial;

- identidade do Método PSV.

NÃO gastar créditos tentando finalizar toda a aplicação.

O desenvolvimento fino será continuado posteriormente no Codex.

Não implementar backend, banco de dados, autenticação, tracking, checkout, integrações ou funcionalidades avançadas nesta etapa.

1. POSICIONAMENTO

==================================================

O Método PSV é uma solução relacionada à estruturação profissional de equipes e operações comerciais.

PSV significa:

P — PROCESSO

S — SISTEMA

V — VENDAS

A comunicação deve posicionar Silvio Luiz Eidt Junior como especialista em estruturação comercial.

A página deve transmitir:

ESTRATÉGIA

ESTRUTURA

PROCESSO

GESTÃO

EXECUÇÃO

PERFORMANCE

PREVISIBILIDADE

VENDAS

Não posicionar como:

- curso genérico de vendas;

- fórmula milagrosa;

- promessa de enriquecimento;

- treinamento motivacional;

- software/SaaS;

- infoproduto genérico.

A percepção deve ser de método empresarial e estruturação comercial.

==================================================

Usar como direção estética:

- programas executivos;

- páginas comerciais high-ticket;

- comunicação de autoridade.

- site feito automaticamente por IA;

- dashboard;

- SaaS;

- página genérica da shadcn;

- site de criptomoeda;

- página gamer;

- infoproduto antigo.

PALETA

Base:

- preto;

- grafite;

- azul-marinho muito escuro.

Destaques:

- azul profundo;

- azul elétrico.

Textos:

- branco;

- off-white;

- cinza claro.

Usar azul como ÚNICA cor principal de destaque.

Não introduzir roxo, verde, laranja ou outras cores de marca aleatoriamente.

==================================================

4. O QUE EVITAR VISUALMENTE

==================================================

NÃO usar:

- emojis;

- blobs coloridos;

- gradientes multicoloridos;

- excesso de glassmorphism;

- excesso de glow;

- partículas;

- elementos flutuantes aleatórios;

- cards em absolutamente todas as seções;

- dezenas de badges;

- sombras exageradas;

- ilustrações genéricas de IA;

- ícones 3D;

- excesso de rounded cards;

- carrosséis;

- elementos decorativos sem função;

- visual futurista exagerado.

Não transformar cada informação em um card.

A página precisa ter composição editorial e alternância de ritmo.

==================================================

5. TIPOGRAFIA

==================================================

Usar no máximo 1 ou 2 famílias tipográficas.

Preferir sans-serif contemporânea, forte e profissional.

Headlines:

- grandes;

- fortes;

- alto contraste;

- excelente legibilidade.

Textos:

- confortáveis para leitura;

- sem fontes excessivamente pequenas;

- largura de linha controlada.

A expressão:

MÉTODO PSV

deve possuir grande presença visual.

Logo abaixo ou integrado:

Processo, Sistema e Vendas.

PSV deve funcionar quase como uma assinatura visual do produto.

==================================================

6. LAYOUT GERAL

==================================================

Criar SOMENTE UMA PÁGINA.

Não criar navegação complexa.

Desktop:

max-width de aproximadamente 1200–1280px.

Utilizar bastante espaço negativo.

Criar ritmo alternando:

- áreas abertas;

- áreas editoriais;

- imagens;

- textos;

- estruturas;

- divisões visuais.

Evitar sequência infinita de cards iguais.

Usar linhas, grids extremamente sutis, tipografia, números e composição como recursos visuais.

A página deve parecer desenhada por um designer profissional.

8. SEÇÃO 02 — O PROBLEMA

==================================================

Título:

Vender mais não começa cobrando mais do vendedor.

Complemento:

Começa construindo uma operação comercial que sabe o que fazer, como fazer e como medir.

Apresentar problemas comuns de uma operação comercial desestruturada:

- cada vendedor trabalha de uma forma;

- oportunidades se perdem por falta de acompanhamento;

- o gestor não consegue identificar onde a venda trava;

- metas existem, mas o processo para alcançá-las não está claro;

- o resultado depende excessivamente de pessoas específicas;

- falta previsibilidade comercial.

IMPORTANTE:

Não criar simplesmente seis cards iguais.

Criar composição editorial.

Pode utilizar:

- textos grandes;

- números;

- linhas;

- colunas;

- divisões;

- destaques tipográficos.

==================================================

9. SEÇÃO 03 — MÉTODO PSV

==================================================

Esta deve ser uma das seções mais importantes da página.

Título:

O Método PSV

Subtítulo:

Uma estrutura comercial construída sobre três fundamentos.

Apresentar:

01

PROCESSO

Estrutura, etapas, responsabilidades e padrões claros para a operação comercial.

02

SISTEMA

Organização, acompanhamento, indicadores e gestão da execução.

03

VENDAS

Transformar processo e gestão em execução comercial orientada a resultado.

Criar uma conexão visual clara:

PROCESSO → SISTEMA → VENDAS

Os três elementos devem parecer partes do mesmo método.

Não criar três cards genéricos desconectados.

PSV deve possuir identidade própria.

==================================================

10. SEÇÃO 04 — TRANSFORMAÇÃO

==================================================

Título:

De uma equipe que apenas vende para uma operação comercial estruturada.

Criar uma comparação visual elegante.

ANTES

- operação dependente de pessoas;

- processos pouco claros;

- gestão reativa;

- baixa previsibilidade;

- dificuldade para escalar.

COM O PSV

- processo comercial definido;

- papéis e responsabilidades claros;

- gestão baseada em acompanhamento;

- equipe orientada à execução;

- maior previsibilidade operacional.

Não afirmar números ou percentuais.

Não prometer resultado financeiro específico.

Criar uma composição Antes → Estrutura → Depois.

Não fazer uma tabela corporativa simples.
